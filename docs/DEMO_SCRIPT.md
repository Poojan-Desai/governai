# Recruiter demo script

## 90-second portfolio walkthrough

1. **Overview (0–12s):** frame the project as an evidence-first governance
   platform and point to the local/live status distinction.
2. **Incident (12–27s):** show four failures, 120 quarantined, zero accepted, and
   identical warehouse before/after counts.
3. **Lineage (27–40s):** select the transaction source and explain computed blast
   radius through metrics, experiments, models, and dashboards.
4. **Experiment (40–52s):** explain stable assignment, a predeclared KPI, and why
   `ADVANCE TO LIVE PILOT` is not a rollout decision.
5. **Governed assistant (52–65s):** answer one approved question, show its cited
   SQL template, then select the blocked injection example.
6. **Model governance (65–78s):** compare time-based MAE, show drift, and point
   to the production approval gate.
7. **Cloud control plane (78–90s):** walk S3→Snowflake→dbt and reconciliation,
   then point directly to “LIVE RUN NOT PERFORMED.” Say the code and local
   contracts are verified but deployment awaits account credentials.

## After a successful live gate

Replace the last sentence only when the generated page reads `VERIFIED`. Show
the three matching reconciliation records, then the quarantine run and the
repeat run that skips duplicate work. Never screenshot raw customer values,
credentials, private keys, account identifiers, or Terraform state.

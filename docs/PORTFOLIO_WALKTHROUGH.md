# Employer and interviewer walkthrough

GovernAI is designed to support a concise product conversation and a deeper
engineering review without changing the facts between them.

## 30-second introduction

“GovernAI is an evidence-first Data & AI governance platform built on safe,
deterministic banking data. It proves a fail-closed quality path, catalog and
lineage, privacy controls, cloud integration contracts, experimentation,
governed analytical answers, and responsible-model gates. The key design rule
is that the interface distinguishes what executed locally from what still needs
cloud credentials, customers, or independent approval.”

## Recommended three-minute route

1. **Portfolio overview:** explain the problem, the trust contract, and the
   difference between verified, implemented, and not run.
2. **Incident center:** show four independent defects, 120 quarantined rows,
   zero accepted rows, and unchanged warehouse counts.
3. **Lineage:** show that the blast radius is derived from stored edges and now
   reaches experiments, semantic metrics, models, monitors, and dashboards.
4. **Experiment Lab:** explain stable assignment, predeclared inference, and the
   live-pilot—not production—decision.
5. **Governed assistant:** select a successful answer, its citation and query,
   then select the blocked injection case.
6. **Model governance:** compare MAE, explain three-fold limitations, inspect
   drift, and show the blocked deployment gate.
7. **Cloud control plane:** finish with the honest live boundary and describe
   the exact reconciliation evidence required to change it.

## Strong interview talking points

- “I optimized for failure semantics and evidence, not the number of services.”
- “The same source hash and batch ID connect ingestion, warehouse audit, dbt,
  reconciliation, lineage, and the dashboard.”
- “A positive experiment or model result never bypasses a separate approval
  state.”
- “The assistant cannot invent SQL; unsupported questions abstain and every
  successful answer cites a governed asset.”
- “The public snapshot contains aggregates and control evidence, not raw PII or
  row-level experiment assignments.”

## Resume-ready bullets

- Built an evidence-first Data & AI governance platform with deterministic
  ingestion, fail-closed quality controls, lineage-derived blast radius,
  privacy metadata, audit evidence, and a React control plane.
- Implemented production-facing S3/Snowflake/dbt/Terraform boundaries with
  idempotent manifests and three-field reconciliation; separated local contract
  verification from unperformed cloud execution.
- Developed independently tested experimentation, governed analytics, and
  responsible-ML workflows with statistical inference, prompt-injection
  defenses, time-based backtests, drift monitoring, and approval gates.

Keep “simulated,” “locally verified,” and “not live-deployed” attached to these
claims in resumes and interviews.
